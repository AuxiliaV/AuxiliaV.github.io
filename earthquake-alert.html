Earthquake Alert Prediction System

A machine learning classification project that predicts earthquake alert categories — Green, Yellow, Orange, and Red — based on earthquake characteristics.

84% Accuracy
Decision Tree Final Model
4 Alert Categories

Project Overview

The objective of this project was to develop a machine learning classification model capable of predicting earthquake alert categories from earthquake-related characteristics.

The project covers the complete machine learning workflow, including data preprocessing, exploratory data analysis, feature selection, model comparison, model creation, evaluation, and prediction.

Objective

To build a classification model that can predict the appropriate earthquake alert category:

Green Lower alert level
Yellow Moderate alert level
Orange Higher alert level
Red Highest alert level

Dataset

782 Records
19 Columns
2001–2023 Time Period
Kaggle Data Source

Data Preprocessing & EDA

The dataset was examined and prepared before model development. Unnecessary columns were removed and exploratory analysis was performed to understand the characteristics and relationships within the data.

Outliers were examined but were not automatically removed, since variations in earthquake characteristics can represent naturally occurring differences that may be important for alert prediction.

Feature Selection

Multiple feature selection techniques were explored to identify useful features for the classification task.

SelectKBest Permutation Importance Forward Selection Backward Elimination

The final prediction workflow uses earthquake characteristics including Magnitude, Significance, and Depth.

Models Evaluated

Multiple classification algorithms were evaluated and compared during the model identification stage.

Logistic Regression SVM Decision Tree Random Forest KNN Gaussian Naive Bayes

Final Model

Selected Model Decision Tree Classifier
Accuracy 84%

The Decision Tree Classifier was selected as the final model after model comparison and was further tuned using hyperparameters.

Model Evaluation

Model performance was evaluated using classification report and a confusion matrix.

Prediction Workflow

The prediction workflow uses selected earthquake characteristics as inputs and produces one of the four alert categories.

Technologies Used

Python Pandas NumPy Matplotlib Seaborn Scikit-learn mlxtend Jupyter Notebook
