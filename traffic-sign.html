COMPUTER VISION · OBJECT DETECTION

Traffic Sign Detection & Classification

A computer vision project using a YOLO-based object detection model to detect and classify traffic signs through a webcam.

52 Traffic Sign Classes
YOLOv8s Detection Model
100 Training Epochs

Project Overview

This project focuses on detecting and classifying traffic signs using a YOLO-based object detection approach. The model was trained using an annotated traffic sign dataset and tested through a real-time webcam demonstration.

Objective

The objective was to develop a computer vision model capable of identifying traffic signs from camera input and displaying the detected sign category along with its bounding box.

Dataset & Annotation

Dataset Source Kaggle
Number of Classes 52 Traffic Sign Classes
Annotation Tool Roboflow
Annotation Format YOLO-Compatible Format

The dataset was downloaded from Kaggle. Roboflow was used to annotate the images and prepare the dataset in a format suitable for YOLO model training.

Model Training

A YOLOv8s model was trained using the annotated traffic sign dataset.

Model YOLOv8s
Training Epochs 100
Image Size 640 × 640
Batch Size 16
Training Device CPU

Webcam Detection Workflow

  1. Load the trained YOLO model.
  2. Open the laptop webcam using OpenCV.
  3. Display traffic sign images using a mobile phone.
  4. Capture the images through the laptop camera.
  5. Detect traffic signs using the trained model.
  6. Display bounding boxes, labels, and confidence values.

The demonstration used traffic sign images displayed on a mobile phone. The laptop camera captured these images, allowing the trained model to perform detection and classification.

Limitations & Future Improvements

The recorded evaluation metrics indicate that the model requires further improvement for more reliable detection across different traffic sign appearances and conditions.

  • Improve dataset diversity and image quality.
  • Increase the number of training examples.
  • Experiment with model and training parameters.
  • Evaluate detection performance under varied conditions.

Key Takeaway

This project provided practical experience in dataset annotation, YOLO model training, computer vision, and webcam-based object detection.
