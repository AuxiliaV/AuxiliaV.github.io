Project Overview

The Support Triangle AI Agent is a workflow-based customer support system designed to handle common support requests through a structured LangGraph workflow.

The agent can determine the appropriate support path based on the customer's request and execute different workflows for order status, refund processing, and customer complaint escalation.

The project also demonstrates a human-in-the-loop workflow for higher-value refunds where the support process requires human approval before proceeding.

Objective

The objective was to build an AI customer support workflow that can handle multiple support scenarios while keeping important business decisions inside controlled workflow paths.

Order Status Check whether an order exists and retrieve its current status.
Refund Handling Check refund eligibility and process refunds according to defined rules.
Human Approval Route higher-value refunds for human approval before proceeding.
Escalation Create an escalation ticket when a customer submits a complaint.

LangGraph Architecture

The support workflow is implemented using LangGraph, with the graph controlling how customer requests move through the appropriate processing and decision paths.

Customer Interface

A Gradio interface provides the customer-facing interaction layer. The customer enters a support request and receives the agent's response through the interface.

For workflows that may require human review, the interface informs the customer that processing may require human approval.

Order Status Workflow

The order status workflow checks the supplied order ID against the available order data and returns the corresponding order information when the order exists.

When the supplied order ID is not available, the agent handles the unavailable-order scenario instead of returning an unsupported order status.

Refund Handling

The refund workflow first checks the customer's order and refund conditions before deciding how the request should be handled.

01. Eligibility The order must be delivered and the refund must be initiated within 30 days.
02. Duplicate Check Existing refund records are checked before initiating another refund.
03. Automatic Refund Eligible refunds of $100 or less can proceed automatically.
04. Human Review Eligible refunds above $100 require human approval before proceeding.

Human-in-the-Loop Workflow

For eligible refunds above $100, the workflow pauses for human approval instead of completing the refund automatically.

In this portfolio prototype, the human approval is handled through the support-agent development/testing environment. The customer-facing Gradio interface remains focused on the customer interaction.

Customer Request Customer submits the refund request.
Human Review Support agent reviews the higher-value refund request.
Decision Approval or denial determines the next workflow path.

Key Learning

This project provided hands-on experience in designing a structured AI-agent workflow using LangGraph, integrating tools into an agentic system, handling conditional business logic, and implementing a human-in-the-loop approval path.

It also demonstrated how a customer-facing interface can be separated from support-agent approval logic within a workflow-based AI application.

Project Limitations

This project is a portfolio prototype and is not presented as a production customer-support system.

The human approval mechanism currently uses the support-agent development/testing environment rather than a dedicated production support-agent dashboard.

The order and refund data used by the workflow are sample project data rather than live production customer records.

Key Takeaway

This project demonstrates how LangGraph can be used to build a structured customer-support agent with conditional workflows, tool execution, refund business rules, human approval, and escalation handling in a single AI-agent application.
